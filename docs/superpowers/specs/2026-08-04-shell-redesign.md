# UI 리디자인: 풀블리드 다마고치 셸 (2026-08-04)

브레인스토밍(비주얼 컴패니언 목업)으로 확정된 방향. 목업: `.superpowers/brainstorm/` 세션.

## 컨셉

폰 화면 전체가 다마고치 기기다. 배경 없음 — 뷰포트 가장자리까지 플라스틱 셸이고,
그 안에 LCD(스테이지)·물리 버튼·쪽지 트레이가 산다. 데스크톱은 480px 중앙 정렬,
바깥은 어두운 무지 배경.

## 토큰

- **셸 컬러**: 내 화면 분신의 `palette` 키(8종)에서 파생한 CSS 변수
  (`--shell-base`, `--shell-deep`, `--shell-text`). `avatarV2/palettes.ts` 색 기반 계산.
  캐릭터 없는 화면(로그인 등)은 기본 크림 셸.
- **LCD**: 팔레트 무관 레트로 그린 고정 (#cfe3b4 계열 배경, #5b4a3f 베젤, #3d4a2c 텍스트).
- **타이포**: 둥근모꼴(PixelKR) 전면.

## 메인 화면

위에서부터: TINYOU 로고 → LCD → 물리 버튼 3개 → 트레이 손잡이.

- **LCD**: 스테이지 캔버스 + 상단 상태줄(Lv·이름·기분·배고픔, 기존 Hud 흡수) +
  하단 XP 게이지. 배부름/스택 캡션·꼬르륵도 LCD 안 텍스트로 (셸 위에 뜨는 글자 없음).
- **물리 버튼**: 밥🍙/쓰담🫳/굿나잇🌙 원형 버튼, 눌림 애니메이션.
  굿나잇은 창 밖 시간에 숨김이 아니라 **비활성(회색)** — 물리 버튼은 사라지지 않는다.
- **트레이**: 하단 바텀시트(CSS transform, 라이브러리 없음). 쪽지 보내기 → 받은 쪽지 →
  설정 순서. 미읽음 배지는 손잡이에. TraceToast/PetToast는 LCD 위쪽 픽셀 말풍선 톤.

## 보조 화면

로그인/커플 설정/대기/캐릭터 생성/단장: 같은 셸 배경 + 내용을 "LCD 카드" 하나에
담는 통일 룰만. 레이아웃 재설계 없음.

## 구현

- `src/ui/shell/` 신설: `Shell.tsx`, `Lcd.tsx`, `DeviceButton.tsx`, `Tray.tsx`,
  `shellTheme.ts`(팔레트→CSS 변수, 유닛 테스트).
- 기존 컴포넌트는 스킨 교체만 — 게임 로직·store·도메인 무변경.
- 검증: 기존 테스트 전체 그린 + shellTheme 테스트 + 모바일(390px)/데스크톱 스크린샷.
