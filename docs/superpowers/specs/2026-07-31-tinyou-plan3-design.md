## 1. 아바타 v2 — 동물 파츠 시스템

- 그리드 32×32 (기존 렌더 슬롯 64×64에 2배 정수 스케일). 기존 16×16 blob 시스템을 대체
- **종 12개**: 햄스터·토끼·고양이·강아지·다람쥐·개구리·새·우파루파·곰·펭귄·오리·물개. 각 종 = `{ key, synonyms(한국어 유의어 배열), baseMap(32×32 문자 그리드 — 외곽선 O·본체 B·음영 S·종 고유 디테일 포함), anchors(눈·입·볼·액세서리 좌표) }`
- **키워드 매핑 (결정적)**:
  - 종: 동물 질문 답변에서 synonyms 부분 문자열 매칭 → 실패 시 전체 답변 재검색 → 실패 시 해시 폴백
  - 팔레트: 색 질문 답변에서 색 사전 매칭(8팔레트: 분홍·민트·라벤더·피치·하늘·레몬·크림·회갈) → 실패 시 해시 폴백
  - 표정(눈 4종·입 4종)·볼터치·액세서리(5종)는 해시(salt 포함) 변형 — **다시 뽑기 시 종·색은 고정, 표정·소품만 변함**
- `generateAvatar(answers, salt)` 시그니처·결정성 유지 (v2 내부 교체). 순수 함수, Vitest TDD
- **기존 캐릭터 마이그레이션**: v2 배포 시 전 캐릭터 `regen_count`를 0으로 리셋하는 마이그레이션 + 접속 시 이름 있는 캐릭터의 regen_count가 0이면 "분신이 새 모습으로 단장하고 싶어해요" 배너 → 재생성 플로우(질문 카드부터 새로 작성 — avatar_seed는 프라이버시상 클라이언트에 노출하지 않으므로 프리필 없음)

## 2. 말풍선 메시지

- **원칙 승계**: 메신저 대체가 아니라 "분신이 배달하는 짧은 마음". 140자 제한
- **DB**: `messages(id, couple_id, sender_user_id, body text(140 체크), created_at, read_at)`
  - RLS: 커플만 select, sender=auth.uid()만 insert
  - read_at 갱신: 컬럼 스코프 grant(update(read_at)) + 정책 "수신자만"(couple 멤버 && sender_user_id != auth.uid()) — Plan 2의 컬럼 스코프 패턴
  - **주의(Plan 2 교훈)**: characters·profiles·messages에 컬럼 추가 시 명시적 grant 필요
- **입력**: 스테이지 하단 "쪽지 보내기 💌" — 텍스트 1줄 입력 + 전송. 횟수 제한 없음
- **도착 연출**: 미읽음 메시지가 있으면 분신이 편지 봉투를 물고 화면 중앙으로 옴(FSM 상태 `deliver` 추가) → 탭하면 말풍선으로 본문 표시 → 닫으면 read_at 기록. 여러 통이면 오래된 것부터 한 통씩
- **말풍선 렌더**: Canvas 위 DOM 오버레이. 무료 도트 한글 폰트(예: 둥근모꼴 계열 — 라이선스 확인 후 셀프호스팅, 외부 CDN 금지) + 손그림풍 삐뚤 테두리(9-patch 도트 이미지 border 또는 SVG). 캐릭터 위치를 따라가는 꼬리
- **받은 쪽지함**: 받은 메시지 최근 30개 목록 화면 (보낸 쪽지는 v1 미포함)

## 3. Realtime

- 커플 채널 1개 구독: `messages` INSERT(즉시 배달 연출), `care_actions` INSERT(상대 돌봄 실시간 반영), `profiles` 변경(파트너 합류 — 대기 화면 자동 진행, 기존 수동 새로고침 버튼 대체)
- 구독 실패 시 기존 fetch 동작으로 자연 강등 (Realtime은 향상이지 의존성 아님)

## 4. 상대 흔적 요약

- 접속 시 마지막 확인 이후 상대의 care_actions를 집계해 토스트 1개: "OO가 어제 3번 다녀갔어 🍙🫳🌙"
- 마지막 확인 시각은 **로컬 저장**(localStorage 키 1개 — 검증단 권고. 멀티기기 어긋남은 수용, Plan 4 재검토)
- 5~10초 리플레이 애니메이션은 이번 범위 아님 (액션 종류가 늘어난 뒤 재검토 — 리서치 문서 참조)

## 5. 굿나잇 의례

- KST 21:00~다음날 03:00에만 활성화되는 "불 끄기 🌙" 버튼. `care_actions.type`에 `goodnight` 추가 (하루 1회 유니크 제약·XP 동일 파이프라인)
- 연출: 오늘 goodnight 기록이 있고 현재 KST 21:00~06:00이면 방이 어두워지고 분신이 이불 덮고 잠듦 (전부 파생 계산, 저장 상태 없음)
- 상대 흔적: "잘 자라고 인사하고 갔어 🌙"
- 시간대 판정도 dateKeySeoul과 동일하게 Asia/Seoul 기준 유틸로 통일

## 6. 기타
